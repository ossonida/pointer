# Pointer

HTML, CSS, JavaScript로 만든 모바일 대응 포인트 카운터입니다. 빌드나 외부 라이브러리가 필요 없습니다.

## 실행

`index.html`을 브라우저에서 열거나, 이 폴더에서 `python3 -m http.server 8000`을 실행하고 `http://localhost:8000`을 여세요.

## 사용

- 처음에는 플레이어가 없습니다. 플레이어 추가에서 닉네임과 컬러를 저장하세요.
- 컬러는 사용 중인 컬러를 제외하고 랜덤 배정됩니다. 직접 컬러를 선택할 수도 있습니다.
- − / ＋ 버튼은 점수를 1씩 변경합니다. 음수 점수도 가능합니다.
- 가운데 점수를 눌러 더하기 또는 빼기를 선택하고 정수를 입력하면 기존 점수에 합산됩니다.
- 이름을 누르면 닉네임과 컬러를 수정하거나 플레이어를 삭제할 수 있습니다.
- 점수 초기화는 플레이어를 유지하면서 모든 점수를 0으로 변경합니다.
- 데이터는 현재 브라우저의 localStorage에 저장됩니다. 기기 간 동기화는 지원하지 않습니다.

GitHub Pages에서 배포할 경우 저장소 Settings → Pages에서 이 파일이 있는 브랜치의 루트 폴더를 선택하세요.
